# Contributing

Contributions are welcome! However, **no pull request will be merged without
explicit approval from the repository owner** (hapynfdj). Please open an issue
first to discuss changes before submitting a PR.

## Guidelines

- Fork the repo, make your changes, and submit a PR.
- Keep changes focused: one PR per feature/fix.
- Update the PROTOCOL.md if you discover new protocol details.
- If you add a new tool or script, add a brief description in README.md.
- Test your changes against a real DELTA-2C lidar or a saved raw log.
- The maintainer reserves the right to accept or reject any contribution.

## Code of Conduct

Be respectful, constructive, and patient. This is a hobby reverse-engineering
project — all contributions are voluntary.
